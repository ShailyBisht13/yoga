# Kewalya Yogshala

Premium Yoga & Wellness website built with React 19, Vite, and Tailwind CSS.

## Stack

- React 19 + Vite
- React Router DOM
- Tailwind CSS v4
- Framer Motion
- GSAP + ScrollTrigger
- Swiper
- Lenis Smooth Scroll
- React Icons

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

```
src/
├── assets/          # Static assets (images, icons)
├── components/
│   ├── common/      # Shared components (Logo, NavLink)
│   ├── layout/      # Header, Footer, MainLayout
│   ├── sections/    # Page sections (to be built)
│   └── ui/          # Reusable UI primitives
├── pages/           # Route pages
├── hooks/           # Custom React hooks
├── services/        # API layer
├── context/         # React context
├── utils/           # Theme, constants, helpers
├── animations/      # Framer Motion & GSAP configs
└── router/          # Route definitions
```
